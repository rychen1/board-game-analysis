# they are not metadata and are not a source of truth.

# Construction:
#   1. The first 50 ids are exactly bgg_boardgames_v0, in that order.
#   2. About 150 additional expected base-game ids were added to widen
#      descriptive coverage across era, player profile, weight, and family.
#   3. The pipeline still skips non-boardgame item types; this list does
#      not change that rule.
#
# Intended coverage (qualitative, not quotas):
#   eras: pre-1970, 1970-1994, 1995-2009, 2010-2016, 2017+
#   players: dedicated 2-player, family/general 2-4, 5+ / party
#   weight: light, medium, heavy
#   families: cooperative, abstract, war, deck-building, area control,
#             drafting, deduction, engine-building
#
